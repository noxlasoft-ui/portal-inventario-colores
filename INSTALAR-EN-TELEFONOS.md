# Instalación en Android y iPhone

La aplicación se publica como PWA en HTTPS: [abrir Portal de pedidos](https://noxlasoft-ui.github.io/portal-inventario-colores/). No necesitas descargar un APK para Android ni un archivo IPA para iPhone.

## Android

1. Abre el enlace en Chrome o en otro navegador compatible.
2. Pulsa **Instalar app** en la barra superior. Si el navegador ofrece el aviso nativo, confirma la instalación.
3. Si no aparece el aviso, el botón muestra instrucciones para usar el menú del navegador y elegir **Instalar app** o **Agregar a pantalla principal**.

## iPhone o iPad

1. Abre el enlace en **Safari**.
2. Pulsa **Instalar en iPhone/iPad** dentro del portal.
3. Sigue las instrucciones: **Compartir → Agregar a pantalla de inicio → Agregar**.

En iOS, la instalación se realiza desde Safari; no se descarga un instalador `.ipa`. La primera visita necesita conexión para guardar la aplicación y cargar el inventario. Cada teléfono conserva sus propios pedidos localmente; no se sincronizan entre Android y iPhone.
