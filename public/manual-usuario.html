Cómo abrir, instalar y preparar pedidos desde un teléfono Android, iPhone o iPad, y una computadora.

Portal de pedidos

https://noxlasoft-ui.github.io/portal-inventario-colores/

El responsable del inventario mantiene y publica el archivo INVENTARIO.xml. Esta guía explica cómo cargarlo y usar el portal.

1. Antes de empezar

Abre el enlace del portal con conexión a internet la primera vez. Elige cómo cargar el inventario:

  • Actualizar desde repositorio (en teléfono puede aparecer como Repositorio): carga la versión central más reciente.
  • Archivo XML (en teléfono puede aparecer como Archivo): permite seleccionar un archivo de inventario que tengas guardado en el dispositivo.

Espera a que termine la validación y aparezca el catálogo. Si el dispositivo ya tenía un inventario y se va a reemplazar, confirma solo si deseas usar la nueva versión. Un XML inválido no reemplaza el inventario que ya estaba guardado.

Para mantenerlo simple: quien administra el inventario se encarga de actualizar y publicar INVENTARIO.xml. Quienes hacen pedidos solo abren el portal y pulsan Actualizar desde repositorio cuando quieran traer la versión nueva.

Android

  1. Abre el enlace en Chrome o en otro navegador compatible.
  2. Para tener un acceso como una app, toca Instalar app si aparece. Si no, abre el menú ⋮ y elige Instalar app o Agregar a pantalla principal; confirma.
  3. La primera vez, carga el inventario central desde el botón Repositorio.

iPhone o iPad

  1. Abre el enlace en Safari.
  2. Toca Instalar en iPhone/iPad en el portal o el botón Compartir (cuadrado con flecha hacia arriba).
  3. Elige Agregar a pantalla de inicio y luego Agregar.
  4. Abre el icono del portal y carga el inventario con Repositorio.

En iPhone/iPad se agrega el portal desde Safari; no se instala un archivo APK o IPA.

2. Usarlo en una computadora

  1. Abre el enlace del portal en un navegador actualizado, como Chrome, Edge, Firefox o Safari.
  2. Pulsa Actualizar desde repositorio para cargar el inventario central. También puedes pulsar Archivo XML y seleccionar un XML guardado en la computadora.
  3. Opcional: si el navegador ofrece la opción de instalar el sitio o crear un acceso directo, puedes usarla. También puedes guardar el enlace en Favoritos.

En una computadora, también puedes arrastrar un archivo XML al recuadro de carga del inventario. No abras el archivo fuente index.html directamente; usa el enlace web del portal.

El portal web funciona en teléfonos y computadoras. No hace falta instalar un programa de escritorio para preparar pedidos.

3. Buscar productos y armar un pedido

  1. Busca por código, descripción, marca o departamento. En el teléfono, usa las pestañas Catálogo y Mi pedido para cambiar de vista.
  2. Selecciona un producto, indica la cantidad y la unidad (por ejemplo, CJ, UND, MT, PAQ o JGO) y pulsa Agregar al pedido. Si es una persiana, elige primero su color; la aplicación no permitirá agregarla sin especificarlo.
  3. En Mi pedido, revisa los renglones y el color de cada persiana. Puedes cambiar cantidades, unidades o colores y quitar productos.
  4. Completa el encargado responsable, el teléfono y el número de pedido.
  5. Cuando termines, pulsa Descargar Excel y guarda o comparte el archivo .xlsx. El pedido muestra el código y el nombre del color seleccionado para que puedan preparar la persiana correcta.

Si necesitas continuar un pedido desde Excel, activa Reposición desde Excel y selecciona su archivo .xlsx. Sus productos se agregan al pedido actual. Revisa los artículos marcados para corregir antes de descargar.

4. Inventario actualizado y datos guardados

  • Después de que se publique un inventario nuevo, cada dispositivo debe pulsar Actualizar desde repositorio y confirmar el reemplazo si se solicita. Publicar el archivo no actualiza automáticamente los dispositivos que ya tenían inventario guardado.
  • El inventario válido y el borrador del pedido se guardan automáticamente en el perfil local del navegador o de la app de ese dispositivo.
  • Los pedidos y los inventarios importados localmente no se sincronizan entre teléfonos y computadoras. Descarga el Excel para conservar o compartir un pedido.
  • La primera visita requiere conexión para cargar la aplicación y el inventario. Luego, la interfaz y los datos guardados pueden estar disponibles sin conexión, pero para obtener el XML central nuevo se necesita conexión.
Privacidad: el enlace público y el XML central pueden ser vistos por cualquier visitante. El Excel descargado incluye una hoja con datos del inventario, que puede contener costos y precios. Compártelo solo con las personas autorizadas y no incluyas en el XML información confidencial.

5. Si algo no funciona

  • No aparecen productos: comprueba que haya conexión y pulsa Repositorio o carga el XML correcto.
  • No se actualizó el catálogo: vuelve a pulsar Actualizar desde repositorio y confirma el reemplazo del inventario local.
  • El XML no carga: pide al responsable que revise el archivo exportado de Stellar. El portal acepta archivos de hasta 20 MB y valida el contenido antes de importarlo.
  • Un producto del pedido no coincide: revisa el artículo marcado con el inventario actual antes de descargar el Excel.
  • No encuentras el Excel descargado: revisa la carpeta Descargas del teléfono o la computadora.
